# 《星灯纪行》A15｜人物与战斗视觉统一深化（本批）

## 修改范围和原则
本批直接修改现有 `main` 的可运行 UI 和角色场景，只负责战斗和 NPC 的**表现层**，不改变十二幕七十二章主线、怪物基础数值、技能伤害、职业判定、回合结算、奖励与存档字段。保留原版四方向人物图集、已有 B02 人物插画、怪物四帧图集与九属性特效。

## 本批实际集成
- 原创战斗美术SVG（`assets/art/battle/a15/`）：我方人物接地阴影、普通敌人地台、Boss地台和施法法阵（4个文件）。
- `battle_actors.gd`：所有在场队员增加独立接地层与施法图层；保留原立绘、攻击位移、倒地、受击、低动态模式。法阵只在施法／治疗／聚星／特殊动作时可见，角色死亡时接地层变暗。
- `battle_enemies.gd`：最多3个敌方位置分别绘制地台；选中目标更突出，敌人攻击时改变地台色彩，死亡动画结束后地台一起淡出。
- `first_act_battle.gd`：只有一个敌人或Boss时也能显示真正的地台，非单体编队维持原多敌人场景流程。
- `world_npc_visual.gd`：对缺少 B02 立绘的世界NPC新增定频、轻量的职业动作：工匠敲击、商人挥手、周期眨眼、任务提示光标；现成B02立绘保持身份外观与小幅呼吸。
- 不新开分支，已有战斗特效系统和音效程序保持原样。
