# 《星灯纪行》第一幕：六处空间差异化布局落地规范（Main2）

> 2026-10-27。设计方向由用户确认的第二版预览效果图引导：明亮自然的海岸系 HD-2D JRPG、清楚的场景层级与易于记忆的地标；原创世界观，参考经典《勇者斗恶龙》的功能清晰度与空间可读性，不复制他人贴图或具体地图。

## 真实玩家地图与六章叙事

现有 42 个世界地图 ID 不增删；五张正式海岸地图对应六个重点场景：

| 玩法场景 | 真实地图 ID | 地形骨架 | 玩家可辨识地标 |
|---|---|---|---|
| 晨露村 | map_coast_01 | 圆形水井广场、南入口、宅邸与菜田小径 | 广场大树、温暖木石民居 |
| 白砂港 | map_coast_02 | 横向堤岸街、后街与南向码头分支 | 木栈桥、帆船贸易、收容所和黑帆酒馆 |
| 盐风古道 | map_coast_03 | 上下高差的连续折返道路 | 瞭望台、旅店驿站、石崖 |
| 断桅海蚀洞 | map_coast_04 | 外环洞室 + 潮阀内环 + 宝箱侧道 | 发光潮潭、钟乳石、三座潮阀 |
| 鲸骨浅滩 | map_coast_03 内现有东南子区域 | 半月形海滩、救援岔道 | 鲸骨标记、退潮潮池、救援平台 |
| 潮歌灯塔 | map_coast_05 | 螺旋折返山路、两级观景台与塔前台地 | 塔体、镜架与失明航灯 |

特别说明：**第三章**经 map_coast_02 → map_coast_03 → map_coast_04 步行入洞，**第四章**原路回港；**第五章**由港进入 map_coast_03 的鲸骨浅滩，不提前解锁 map_coast_05；**第六章**才沿洞窟出口登上灯塔。旧档出生在灯塔时仍只能按既有路线退回。

## 实际工程接入（可复用的 V3/V4 结构）

- `data/levels/v3/map_coast_01..05.json`：各地图拥有独立多段道路、地形阻碍、真实可走空地、显著地标与扩展节点；旧 ID 和尺寸保持。
- `scripts/world_geography.gd`：让晨露村/白砂港真正按独立 V3 路道生成；古道与灯塔支路并入主线最近节点而非共享同一星状中心；海洞环路真正切进实机碰撞。
- `data/levels/town_director_v4.json` + `scripts/town_director.gd`：区分圆心村庄与横向商业港口，服务建筑/居民仍保留原始可互动 ID。
- `scripts/world_structure.gd`：村庄暖色瓦顶与港口冷色石顶的建筑备用画法差异；玩家屋门位置及内外传送保留。
- `data/levels/v4/coastal_scenery.json`：新增真实引擎使用的场景美术节点，遵守现有合法 PNG/重定向资源分配，不从海量原始候选包搬入无用素材。
- `tools/validate_act01_distinct_layouts.py`：验证独立设计数据、原故事路径与必需清空区。
- `tools/smoke_act01_distinct_world_layouts.gd`：使用 Godot 实际检查五图、城镇房屋、海蚀洞潮阀、浅滩救援点和出入口的连通性。
- `tools/capture_act01_distinct_layouts.gd`：通过真实 Godot 图形输出六张无剧情框挡住地图的游戏截图；截图不等于人工画质验收。
- `.github/workflows/main2-map-regression.yml`：地图、美术或运行逻辑更新会触发完整地图测试，成功后采集图像证据。

## 商业品质验收约束

1. **设计不重复**：五地图各有独立主路拓扑、区域密度和显性地标，鲸骨浅滩拥有额外的独立情绪空间。
2. **可走**：必须从当前出生点走到所有相邻出口；每个室内门口和剧情锚点周围具备真实连通的可站立地砖；不能通过菜单瞬移替代步行。
3. **脚本不回退**：地图美化不能破坏 72 章地图对应关系、第一幕章节锁、战斗、NPC、存档、重载或原始房屋 ID。
4. **正式素材**：仅将已接入场景的合适美术送入精简 Runtime，重定向的旧材质必须按真实语义检查，不能把源包统计当成可用素材。
5. **人工画面验收**：项目须有人审阅每张地图的全貌、夜晚、无遮挡地形、室内与怪物动作；自动截图或脚本成功不能取代实机手感。
