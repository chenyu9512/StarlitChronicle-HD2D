# 第72章：结局系统与终章验收

本文件记录游戏主体 **main** 的三结局判定与后日谈系统。正式数据从 `story/data/endings.json` 和 `story/campaign/act_12.json` 读取，不复制剧情到程序里。

| 结局 | 中文名称 | 需要满足的条件 |
| --- | --- | --- |
| A | 守灯之世 | 第71章决战胜利、第72章主线尾声 |
| B | 无灯之晨 | 第71章决战胜利、第72章主线尾声 |
| C | 万家星灯 | A/B条件 + 全12张失落航页 + 第60章分散灯网 + 第66章七灯修复 |

## 游戏流程

完成第72章场景3的最后对话后，地图上的归航灯坛出现第5段终局事件。执行终局对白后弹出三个选择；C在没有达到条件时会显示🔒与需要补足的具体条件，按钮不能误选。选定结局后依次播放该结局独立的4场后日谈。后日谈每完成一场就存档 `ending_scene_index`；退出后继续可以恢复未完成部分。四场全部结束才记录 `story.complete` 和结局档案。

结局档案已经整合到游戏 **功能手册 → 结局档案**，已通关结局可回放且不会更改存档最初选择。新游戏与旧版数据并存；结局状态随通用 `rpg` 字段写入存档。

## 验收

`tools/smoke_campaign_72.gd` 验证72章主流程与结局A完成；`tools/smoke_endings.gd` 验证三选项条件、12张航页、真结局解锁、4场独立后日谈、保存/恢复与回放。由 `.github/workflows/godot-core-validation.yml` 的 Godot 4.7.2 无界面运行。

## 产品化尚需

三结局剧情演出目前使用游戏现有对白层。未添加独立电影式过场、分支专属CG/BGM、演出音效与多语种字幕。关卡视觉与iPhone实体设备仍需进行发布级验收。
