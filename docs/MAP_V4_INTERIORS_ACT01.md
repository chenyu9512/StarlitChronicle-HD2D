# 地图 V4：晨露村与白砂港独立室内首批

本次继续使用既有 `WorldGeography.interior`、建筑进出、`rpg.world.indoor_building` 和室内交互键名，新增 V4 JSON 加载适配器，并非重建一套世界系统。

- `scripts/world_interior_v4.gd` 读取 `data/levels/v4/interiors/<map_id>__<building_id>.json`；输出原格式的地形、碰撞、陈设、出生点和服务坐标。
- 晨露村/白砂港各6间：客栈、商店、公会、工房、住宅、祈灯祠，共12个独立平面与隔断，所有服务点可从入口抵达。
- 内部出口、服务和储物入口从各关卡定义取坐标；原有剧情与存档字段不变，其他区域建筑仍使用原室内后备生成方案。
- Godot `smoke_world_production.gd` 逐间检验V4数据、唯一碰撞拓扑与服务点可达，并检查客栈→街道→商店→街道的真实节点切换。

**交付范围是室内物理关卡首批，不是最终室内美术/音乐、NPC日程、全局房屋系统或商业发行验收。** 后续须精修家具交互、NPC占位、差异化音画及全部后续区域室内地图。
