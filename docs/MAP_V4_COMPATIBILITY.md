# 星灯纪行｜地图 V4 兼容性修复（第一批）

> 此文件记录已提交的运行时修复范围，不代表“地图 V4 已完成”或“40区达到商业美术标准”。

## 既有管线与缺陷

- 继续使用 `world_level_v3.gd`、40张V3独立关卡、`world_geography.gd` 和旧存档中的地图ID，没有另建不兼容的地图系统。
- 原野外关卡先执行 `paint_overrides` / `collision_overrides`，后续任务锚点与出口自动连路可能覆盖这些修改。
- 城镇/地下城的 V3 障碍线和水道线未通过 `apply_safe_paths` 进入碰撞；`water_mask` 也只在野外生成。
- 海岸地图渲染器对地表行号和底部高度做兜底水面判定时，没有检查最终碰撞，导致可走的桥面可能被当成水。

## 本批修正

1. 所有地图类型均允许 V3 独立地图上的 `obstacles` 与 `waterways` 写入地面和物理阻挡；城镇/地下城保留原有结构保护，不让装饰道路随意开凿剧情墙体。
2. 自动任务连线及出口连线完成后，再统一重放逐格 `paint_overrides` 与 `collision_overrides`，明确以关卡设计师最后修改为准。
3. 城镇/地下城也生成同源水面遮罩，人工设置 `blocked: false` 的水道格作为桥面，不再呈现不可通行的水面。
4. 地面贴图、玩家碰撞、小地图统一从最终地形/碰撞读取。该改动不更改旧地图ID、剧情章序、存档结构。
5. `tools/smoke_world_v3.gd` 新增三类地图的真实 `geo.layout()` 回归：测试出生位置、自动出口、山体、水道以及可通行桥面的最终数据。

## 必须继续的验收

- 当前只完成 V3→V4 地形兼容层修复，**未交付**独立场景制作者、全城室内装饰、完整地下城谜题、40张手工地图或第一幕通关验收。
- 修改城市或地牢的障碍/水道仍可能隔断关键任务，原 `smoke_world_v3.gd` 与 `smoke_world_production.gd` 的关键任务、城镇门口和出口可达性回归继续作为硬门槛。
- 通过 GitHub Actions Godot 4.7.2 运行结果确认脚本解析、地图连通、地图UI与第一幕兼容性；真实设备/人类实玩另行验收。
