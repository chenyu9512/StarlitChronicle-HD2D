| 当前原型 | 正式长篇剧本 | 决议 |
|---|---|---|
| 黎昂（玩家角色） | 可自定义主角名（默认可取“黎昂”） | 后续角色数据迁移时保留默认名 |
| 澪（原型同伴） | 岚音（童年好友与药师） | 目前仅当暂用资源，不立即覆盖存档 |
| 晨露村 | 晨露村（白砂海岸内陆） | 继续沿用地图名 |
| 星落遗迹 | 第一幕近海古遗迹与序章预兆地点 | 保留资产、再补正式剧情 |
| 守灯人寻找星核 | 序章里一场独立的引导试炼 | 过渡为正式的星针线索，不等于修复母灯 |
| 两人固定队伍 | 主角 + 八名核心伙伴、最多四人出战 | 待阵型/装备/存档V2时实现 |
| 原版 quest_stage 0/1/2 | `story.*` 事件旗标及多分支任务状态 | 当前V1存档不能直接自动迁移，须写V2迁移器 |

**实施规则**：先新增只读剧情内容、预览器和资源加载层；当章节事件与存档V2模块成熟后，单独提交从原型任务链迁移到正式序章的可回滚补丁。
