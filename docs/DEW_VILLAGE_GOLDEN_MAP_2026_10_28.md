# 晨露村 · 第一张正式地图改造（2026-10-28）

执行范围：仅 Main2 美术优化版的 `map_coast_01` 正式运行地图，不建立新开发分支，不改 main。

## 实际修改
1. 地图生成器正式切换 `dew_village_ring`。以已有水井(35,21)为集市广场真实核心，不再沿用地形正中心(48,28)产生第二个广场。
2. 不再绘制通用城市十字主干道；恢复 V3 已编写的弯曲环形石路与6条独立村巷，村中6间建筑的入口就近连接到已有村巷，降低穿越菜圃/民居的蜘蛛网道路。
3. 石板环路的可见表层直接采用现有经身份核对的 V18 Golden Horizon `cobbles.png`，只在地图确实可行走、没有碰撞或水的格子叠加，以微小纹理变化代替大面积死板方块。
4. 把村庄市场摊位从西南旧屋区(22,34)移动到东侧商业街附近(53,27)；花篱从村庄广场主路(39,30)移至西南菜圃(18,40)；第二棵古树从工坊门口(53,39)移到村东郊(64,41)。全部保留素材原文件、对象ID与非阻挡属性。
5. 沿旧有通行路径添加轻微暖石缝与沙地边缘。保留原城镇结构/碰撞封闭与门口对照、任务/存档ID，不跳过Boss。
