# 《星灯纪行》B01 美术资源原型交付

本资料包是**初版程序化原型资产**，不是已全部达到商业级水准的成品图。作为用户要求的15类资源**可下载生产起点**，目的是提供实际独立 PNG、Godot 可读取资源路径、批次规范、独立图块与映射清单。

生成 PNG 共 1091 张；此外有 JSON 布局、CSV 映射和验证报告。文件尺寸按实际 manifest 查看。

## 内容
- `tilesets/`：8个地区，每地区一份256x256、8x8格的32px方形图块原型。地形图块在各地区有不同配色和笔触。
- `maps/`：40张768x576的独立地图底稿 + 40份JSON数组布局（不含碰撞和真正剧情地图验证）。
- `timeline/`：8地区首图各2个时代视觉变体，合计16张视觉原型，**不代表全部地图时代差分已完成**。
- `characters/south_32x48/`：158个独立南向人物原型：12主要人物、40地区NPC、106支线称谓映射（同名身份有待审定）。
- `characters/preview_4x/`：以上158位像素最近邻4倍放大图，**仅预览不是新立绘**。
- `monsters/`：63种普通怪物独立立绘+4帧上下浮动示例，**不是63种真正完整攻击受击动作**。
- `bosses/`：66个剧情Boss独立剪影原型 + 两种相位光环效果，**仍是结构占位草图，不是66张成品Boss立绘**。
- `icons/`：81武器+54防具+90物品+20职业+63技能+12调查标记，均为独立图像；部分技能图标使用通用序号，占位等待正式技能ID绑定。
- `lamps/`：七母灯 x5种状态，共35张PNG。
- `ui/`：14个功能模块界面布局原型，**不是完整UI组件皮肤**。
- `story/`：15张重点剧情分镜底稿+3张结局构图底稿，**不是正式CG**。
- `mappings/`：角色索引、Boss索引、384调查点模板映射。384个标记指向12个模板，不代表384张原创调查插画。

## 重要限制
1. 已交付的图片为程序性绘制像素草稿，审美与一致性需要人工审核；与早期SVG及AI概念画**不能直接宣布替换**。
2. 32x48南向只有1帧，尚无左/右/上、行走、攻击、受击等动画。
3. 40张地图是初版视觉排布，未匹配72章全部地图调度，没生成Godot `.tscn`；JSON仅是参考底稿。
4. 66个Boss效果使用基础剪影构成，尚未按剧本的专属结构逐一精修，禁止当成最终敌人设计。
5. 检测不到正式游戏运行状态，本次**不修改GitHub main，也不改变已有程序**。
6. 资源引用使用ASCII路径，中文只放manifest展示字段；PNG均为分离资源，不从拼图自动误切。
7. 角色设计参考先前用户确认的角色设定表，对尚未锁定的肤色、发型、职业造型仅做初稿，不宣称是原著既定外貌。

## Godot试导入建议
将`characters/south_32x48/*.png`等对应素材拷贝到项目试验目录`res://assets/art/_incoming/`，用Godot 4.7.2的Sprite2D查看1x、2x、3x缩放并设置Nearest，再验收命名、透底、碰撞、逐帧一致性。

## 为什么不打钩全部15项
交付涵盖全部15模块的**某些初始资产或映射**，但距离“完成”验收目标仍有实质差距。尤其没有12人完整套图、没有63怪全动作、没有66Boss成品设计、没有正式剧情CG。
