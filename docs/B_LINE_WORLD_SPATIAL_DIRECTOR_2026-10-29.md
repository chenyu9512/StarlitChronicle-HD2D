# 星灯纪行 B线｜正式世界空间与关卡交付规范

**项目**：StarlitChronicle-HD2D（Godot 4.7.2）  
**唯一编辑分支**：`Main2美术优化版`；不改 `main`。  
**状态**：本轮正式运行代码已改动；全地图实机与商业级画面验收**未测试**，不得标记“完全完成”。

## 1. 正式数据权威与坐标

1. 世界 ID / 相邻关系 / 建筑及外部门口：`data/levels/world_atlas_v2.json`（42个节点，其中40个可玩）。
2. 每图真实地面、道路、障碍、水域、扩建节点：`data/levels/v3/<map_id>.json`（40份，优先于合并版 `world_levels_v3.json`）。
3. 所有室内可走区域、墙面、家具阻挡、调查、服务点、剧情点：`data/levels/v4/interiors/<map_id>__<building_id>.json`（原有99份，本轮新增54份，目前153份）。
4. 正式关卡生成和最后的物理校正：`scripts/world_geography.gd`。
5. 游戏实际渲染 / 玩家实体 / 最终阻挡 / 建筑事件：`scripts/first_act_world.gd`。
6. 视觉素材：继续调用 A线既有正式资源入口；B线仅修改场景位置与物理层，不另造纹理注册系统。

**统一坐标**：左上角为 (0,0)，整数 `Vector2i` 地图格，每格 32px；世界像素位置取格心 `tile*32 + Vector2(16,16)`。任何碰撞、门口、NPC、调查点、出口、标记均必须引用当次正式加载的 `terrain_layout`，不能另做一份偏移坐标。

**C线接口**：`FirstActWorld.export_map_spatial_contract()` 返回 `schema`、`map_id`、`interior_id`、`tile_size`、`size`、`spawn`、`blocked`、`gates`、`markers`；`markers` 的键是当前实际 `nodes` ID，内容有 `cell`、`world_position`、`visible` 和 `title`。供小地图/任务方向标记读取，不改 C线 HUD。

## 4. 153间V4室内的不可退让条件

`world_interior_v4.gd` 使用同一套最终隔墙 + 门区 + 家具碰撞格，按四邻域真实步行进行连通性校验。必须从 `points.spawn` 可达：出口 `exit`、服务 `service`、储物 `storage`、主线5阶段剧情点、支线 `quest_points` / `story_stage_points` / `branch_stage_points` 和调查 `investigations[].cell`。不允许把检查失败改成瞬移、忽略碰撞或篡改任务进度。

- 收容所：门口入院通道—登记台—病床及治疗区—药柜—剧情证物；病患与剧情人形不能封路。
- 黑帆酒馆：进门地毯—桌椅区—吧台服务—公告栏与货单调查—返程门，所有家具碰撞与NPC对话站位分开。
- 住宅：门口—生活区—家具调查点—储物—返回，不让卧床与餐桌堵住屋门。
- 旅店/商店/工坊/神殿/剧情支室：各用正式V4中的功能配置；以真实 `map_id#building_id` 匹配外部门牌，不把不同房间合成一间通用空屋。
