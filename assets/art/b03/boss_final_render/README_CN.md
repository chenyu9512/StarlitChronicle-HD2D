# 星灯纪行 · 第一幕5场Boss高清透明美术

直接来自5张各自独立生成的Boss立绘，不是B01简笔画、不使用B03旧SVG，也不是宣传拼版截图。

## 资源
每场Boss：1254×1254 RGBA母图 + 768×768 RGBA战斗版本（含安全边距）。

顺序：第2章雾潮寄生体；第3章潮痕守卫；第4章灰帷水手；第5章缚潮古兽；第6章潮歌守门人。

## 使用
这批是可直接用作静态战斗立绘的独立透明资源。动画、攻击分帧和受击分帧需单独制作；不应将一张静态立绘误认为完整动画。

## 发布规则
仅新增到 `assets/art/b03/boss_final_render/`；不修改B01/B02、不替换原有已接线的战斗图片、不创建分支、不强制推送。`manifest.json` 记录对应Boss ID和文件SHA-256。
