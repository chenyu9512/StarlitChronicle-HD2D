## 运行与版本识别

- **正确仓库**：`chenyu9512/StarlitChronicle-HD2D`，分支 **`main`**。
- **当前主场景**：`scenes/first_act.tscn`，Godot 4.7.2 导入 `project.godot` 后按 F5。
- **玩法**：实地追踪剧情目标；每章可完成一条支线；第2—6章各有Boss，第4章后朔弦入队。
- **存档**：`user://first_act_v3.json`，旧版 `scenes/main.tscn` 和老存档仍保留。
- **调试入口**：4秒内连点右上角星星5次 / F10，密码 `9169`。
- **自动化**：Godot 4.7.2 导入、场景启动、9场序章、6章目标、6支线、5Boss、最终旗标检查已通过。
