## 实际代码调用路径

- `EncounterRegistry.story_boss()`按剧情ID加载Boss配置，`EncounterRegistry.roll_monster()`按72章目标缩放怪物HP/攻击/经验/金币。
- `FirstActBattle.start()`实例化`BattleBossMechanics`，`_begin_round()`调用`round_effects`与`intent`；`_act()`调用`record_action`，处理真实战术指令；`_enemy_action`处理实际攻击/异常，`_finish`分辨结算。
- `CombatRules.vocation_damage/vocation_skill_power/vocation_mitigation`从实际出招路径读取职业被动。

## 共享接口待统一整合（未修改受保护文件）

参考`scripts/first_act.gd`当前blob SHA `609ea362239370511d3f1639df9e9f196c9c7652`。在`_battle_finished()`清空`battle`指针之前读取：
```gdscript
var a_settlement: String = str(battle.last_boss_settlement) if is_instance_valid(battle) else ""
```
将旧固定Boss胜利横幅`强敌已倒下`改为按`a_settlement`显示：`nonlethal=安全解除控制`，`rescued=救援完成`，`defeated=强敌已倒下`。胜利事件字典写入结算值供剧情系统识别；奖励只结算一次，避免非致命结算被视为击杀。

`scripts/rpg_core.gd`（共享受保护）目前仅限制武器，不限制护甲职业；统一整合须引入护甲标签验证、转职不合法装备返包和存档兼容。`scripts/first_act_state.gd`持有独立实际角色升级公式，72章规划目标并不会自动覆写其成长；需要统一验证实际经验曲线和新目标是否相符。
