## 游戏运行方式

```powershell
git clone -b main https://github.com/chenyu9512/StarlitChronicle-HD2D.git
```

Windows 上安装 Godot 4.7.2，选择导入仓库根目录 `project.godot`，等待资源导入，然后按 **F5**。

- 正式主体入口：`scenes/first_act.tscn`
- 历史原型场景仍保留于代码内：`scenes/main.tscn`
- 当前通用存档：`user://first_act_v3.json`（历史文件名继续沿用，新增RPG字段向后兼容）；旧版v1存档不会被覆盖
- 移动：WASD / 方向键 / 触屏方向控制；调查：E / 屏幕按钮
- 隐藏金手指：右上角星星4秒内连点5次，或按 F10，密码 `9169`

## 当前已接入的游戏内容

- **完整主线运行框架**：童年序章 + 12幕72章对白、选项、事件战斗、任务结算、角色入队和进度存档；后续章节复用地图系统，**不是72张独立手工场景**。
- **三结局正式接线**：A 守灯之世、B 无灯之晨、C 万家星灯。C需要12张失落航页、分散灯网和七灯修复；各结局有4段独立后日谈、恢复与回放，见 [结局设计说明](docs/ENDING_SYSTEM.md)。
- **RPG功能栏14大栏目**：队伍、背包、武器、防具、技能、职业、任务、世界地图、地区探索、图鉴、商店、锻造、结局档案、设置。
- **通用玩法数据**：81把武器、54件防具、63项技能、20种职业；支持装备属性计算、购买出售、锻造、道具使用、四人出战和经验成长。
- **世界支线**：36条原创支线（12条失落航页 +24条人生线）、48条同伴任务和36条地区任务。任务菜单可按类型过滤和选择追踪，地图实体负责互动阶段。
- **区域剧情层**：72章每章两处独立调查物件、一段中段证言及随进度变化的NPC对白；调查、任务与结局条件均保存至通用状态。
- **第一幕保留**：1—6章已有的地图交互、6条基础实地支线和5场Boss机制保持兼容，隐藏9169金手指可贯穿全篇。
- **旧存档**：针对v0.3的第72章旧通关标记加入迁移路径，不删除背包、金币与角色成长数据。

**发行边界：** 当前是72章可由同一剧情事件控制器运行的开发框架，并非72章都已有独立地图、专属NPC造型、Boss动画、独立过场及音乐。系统和数据已贯通，但数值平衡、完整美术、iPhone真机测试与商业发行验收仍需要后续工作。
