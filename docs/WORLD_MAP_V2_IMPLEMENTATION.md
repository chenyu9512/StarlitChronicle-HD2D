# 星灯纪行｜世界地图与城镇关卡实装说明（地图 V2）

> 本文记录已经进入 `main` 的可执行代码、玩家能够操作的功能、数据来源与尚未通过的商业级验收，不是另一个概念性规划。

## 实装边界

- Godot 4.7.2，进入地图复用现有 `scenes/first_act.tscn` 与 `scripts/first_act.gd`。**地图以独立空间配置 + 运行时 TileMapLayer 绘制，并非40个分别手绘完成的 `.tscn` 场景。**
- `data/levels/world_atlas_v2.json`：42个有地理位置的节点、8大地区/地貌、40个正常游玩地图与两个不开启的旧版本原型。保存 `atlas` 坐标、`sector` 分块、相邻道路、区域主题、城镇建筑位置、地下城房间网络。
- `scripts/world_registry.gd`：保留 `data/content/maps.json` 与72章任务映射的权威解锁规则，`shortest_route` 只能经过可发现且已解锁的图节点，不会越过章节条件。
- `scripts/world_geography.gd`：使用空间目录将每处独立地图生成72×48 TileMapLayer 地面、障碍、区域地貌及可走道路；场景返回或章节变化仍维持固定拓扑。
- `scripts/first_act_world.gd`：玩家角色、镜头、Y轴排序、实际碰撞、交互标记、野外出口、建筑门、室内地图与回到原位。移动中的区域只加载一处，不同时渲染40张地图。
- `scripts/world_structure.gd`：项目原创 Godot 绘制的城镇建筑，区域调色与客栈/商店/公会/锻造/住宅/祠堂的顶视辨识符号，不使用勇者斗恶龙系列版权美术。
- `scripts/map_view.gd` + `scripts/map_hud.gd`：25×17格跟随玩家的小地图、当前区域72×48全图、地区分块放大图、全世界分区图。标注当前角色、主线、支线、服务建筑、地区出口；世界可点击地点并查看已解锁的安全路线。

## 世界结构与城镇

八大区域：白砂海岸、三誓诸国、赤炉联邦、海歌群岛、镜眠王国、失落旧洲、天轨圣域、群灯之城。全地图的42个位置由原有权威目录提供ID/名称/路由；两个原型不开放，40个主游戏区域正常显示。

11个聚落/城镇区块铺设6种街道布局：中央广场、阶梯街区、码头水岸、环形商区、城墙分区、水道住宅。建筑绘制与门口位置来自同一条配置；进入室内后可实际步行、调查设施、从出口返回，且不会重新出生在错误的街区。

八座地下城在世界配置中有不同的 `dungeon_chambers` 房间网络，提供障碍墙、连接廊、交叉路、符文机关、特殊宝箱。野外路线包含可行走道路、隐蔽补给与休憩点。地下城两个符文的状态与打开宝箱的记录写入原存档，奖励不能重复刷。

## 操作

- 探索小地图：进入野外/城镇时显示；打开操作与原键盘 TAB / P 或触控小地图标题一致。
- 当前地图：显示地形、玩家位置、主线/支线和出口。
- 地区分块：查看当前地区的街区/地牢/野外节点地理关系。
- 世界航路：显示8地区的轮廓与全部40个正式节点；未发现的节点名字隐藏。点击地点可见道路路线。跨多张图旅行只执行**当前合法的下一站**，不能直达尚未解锁的远处节点。
- 城镇门口：移动到建筑门前使用原交互键进入，室内寻找“出口”标记返回。
- 洞窟宝箱：依次找到两座符文机关，完成后打开独立秘藏。支线机关不会阻断原本的主线Boss路线。

## 可重复检查的验收脚本

- `tools/smoke_world_production.gd`：40个可玩地图的72×48地面、出生点、主线/支线交互点、相邻出入口可达性；11个城镇建筑门和室内返回；6种不同街道风格、8种不同地下城障碍拓扑；三个地图视图。
- `tools/smoke_world_story_interactions.gd`：地下城符文与单次掉落保存，旅程多段最短路不跳过锁、冒险手册能打开世界地图。
- `tools/smoke_map_ui.gd`：地图缩放、地图标记、弹窗状态和原剧情旅行权限。
- `tools/smoke_campaign_72.gd`：72章实际主线交互，防止场景增加建筑门后遮挡任务标记。
- 入口：`.github/workflows/map-ui-validation.yml`（地图快验），`.github/workflows/godot-core-validation.yml`（完整脚本回归）。

## 尚不能宣称已完成的商业成品验收

1. 当前40个区域是**稳定的独立数据布局和运行时地形**，部分几何由确定性规则绘制，不是40套人工逐块摆放的正式TileMap/关卡美术。
2. 城镇室内已可走可退出，但并非每栋房子都有专属剧情NPC、家具摆放动画、昼夜变化和独立声场；商店/公会/居民互动需要更深的城市内容制作。
3. 野外目前的场景规模为每块72×48格，加总为跨区世界网络；还未做一个无缝横跨8地区的大型3D地形。
4. 地下城拥有不同房间网络和机关循环，但未全部完成专属Boss房的手工镜头、视效、独特谜题及艺术关卡演出。
5. 美术与音频仍需针对每个区域补完最终资源；通过程序性资源检查不等于达成商业审美。
6. iPhone横屏UI的Safe Area、触控命中热区、长时间连续探索帧时间与完整真机通关仍需在设备上验证。

结论：地图V2的**主要功能框架、实体路由与覆盖面已经进入游戏**，不应把上述待验收的人工关卡、美术及设备任务标记为已完成。
