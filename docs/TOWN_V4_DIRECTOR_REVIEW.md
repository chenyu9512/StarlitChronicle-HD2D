# 星灯纪行｜城镇 V4：资深 JRPG 关卡总监审查标准与实装

本次优化参考《勇者斗恶龙》系列的**关卡可读性、强地标、紧凑探索、功能预期、生活气息和故事动线**。不复制其版权地图、建筑外形、角色、音乐或画面素材。

## 已实际开发的内容（不是只有规划）

- `data/levels/town_director_v4.json`：11座城镇逐一设计，每座有独立主题、世界观材料、入口视觉锚点、1座公共广场、4个功能街区、16个明确摆放的文化/生活物件。合计 **44个街区与176处主题陈设**。同一张港口地图不再与工业镇共用随机棕榈树/木桶摆放。
- `scripts/town_director.gd`：实际将广场主轴、街区边缘、广场铺装和独立装饰写入游戏的 `TileMapLayer`，并校验物件坐标。美术陈设只在已可走区域出现，不会挡住建筑和剧情通道。
- `scripts/world_geography.gd`：11张城镇地图使用独立分区；把自由议事厅恢复为**城镇公共建筑**，不再被误当作地下城。
- `data/levels/world_atlas_v2.json`：熔炉港、天轨前庭与王都三个街区的客栈、公会、商店、住宅等实体建筑位置独立设计，减少大量重复建筑图。
- `scripts/first_act_world.gd`：去除11座城镇复用的固定旧装饰列；日间让商人、工匠和公会人员靠近**实际营业入口**，夜间居民/传闻NPC回到生活区；继续保护章节交互标记。
- `scripts/map_view.gd`：完整城镇地图能够标示已探索的功能街区；小地图维持清爽，不铺满标签。
- `scripts/world_geography.gd::interior()`：客栈、商店、公会、工房、住宅和祈灯祠具有**各自八件明确安排的可视陈设**，各设施的原有服务操作、返回出口与存档保持不变。
- `tools/smoke_town_direction_v4.gd`：以Godot实际验证所有城镇入口→广场、剧情点、建筑门和出城通道可达；每座不同的场景身份、六类室内用途，以及世界图中“议事厅”的正确分类。
- 工作流 `.github/workflows/map-ui-validation.yml` 与 `godot-core-validation.yml` 已加入此批关卡审查。

## “商业成品”必须跨过的关卡

1. **认路**：从任何入口，应能迅速辨认一个主地标；客栈、商店与出口的路径应清晰，不能强迫玩家反复查菜单。
2. **空间层次**：要有宽窄变化、广场留白、次级小巷、远景焦点与地区特色，而不是无意义的满屏铺装。
3. **建筑可信度**：屋顶、立面、材料和功能应符合地区气候与生产方式，不能所有建筑只是颜色替换。
4. **生活可信度**：人跟功能相关，渔民在港口、工匠在工房、居住NPC在邻里；昼夜有不同的日常节奏。
5. **互动稳定性**：不丢任何72章的主线标记、商店接口、住宅回位、迷雾存档，边界和剧情节点必须可达。
6. **视觉审查**：需对每座城镇制作真实游戏截图，由关卡、美术、UI负责人逐一审视比例、留白、摄像机取景、建筑质感和素材一致性。
7. **真机检查**：电脑键盘/手柄、触屏、横屏安全区域和长时间帧率测试。

**当前验收范围**：已落地的是“空间设计数据与实际运行功能”，不是《勇者斗恶龙》级别的最终原创美术素材。请勿将 Godot headless 关卡回归冒称为人工美术验收。下一步还需替换现有以程序绘制为主的建筑外观、逐城制作更完整的室内专属美术，并完成真实玩家路径和镜头验收。
