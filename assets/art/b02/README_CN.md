# 星灯纪行 B02｜美术精修首批角色母稿

这不是B01全1,091张商业级重绘。

实际交付：12名主要角色、35名NPC，共47个从此前生成的高细节人物立绘中独立提取的视觉母稿；每人4个透明PNG（全身母稿、320×400肖像、192×240对话、160×160头像），合计188张图片；另附8张此前原创地区风格概念图用于风格统一。

## 使用
- 人物身份以MANIFEST.json和INDEX.csv为准。
- 这些素材已独立透明化并完成尺寸导出，但高分辨率人物立绘和真正的32×48行走精灵不是一回事。不要将肖像图伪装成4向12帧动画。
- 建议先用于Godot角色图鉴、对话肖像、外观审核；完成表情、方向动作、换装后再替换正式游戏素材。
- 提取的透明边缘仍需细查。无损源画来自以前的多人原画；若发现衣摆、飘带被截，应人工修正。
- 这7个NPC地区为三誓、赤炉、海歌、镜眠、旧洲、天轨、群灯；白砂海岸5位目前没有达到相同质量的可靠全身母稿，因此未强行拿简笔画顶替。
- 地图、怪物、Boss、装备、母灯、调查物、剧情CG、UI尚未商业级完成。

## 画风指导
每个主要人物保持独特服装结构，NPC服装不要统一深蓝/白色大制服。不同地区使用独立布料、材料、生活道具，禁止把旧B01原型统一上色伪装成新美术。

另含32张从此前8张原创美术风格板提取的怪物/造物视觉参考图。它们属于概念裁片，不是63种怪物的定稿、透明战斗图或动画。
