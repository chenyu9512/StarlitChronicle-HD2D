# 《星灯纪行》V7 第二批：11 座聚落独立生态

> `main` 实际开发记录。以现有 V4 城镇导演、40 张 V5 地图、V6 探索及 V7 地下城机制为基础增量制作，不替换72章主线、120条支线和原建筑入口。

## 本批完成的仓库改造

- 为现有 **11 个正典聚落**单独编排一个具有地名、文化和产业特色的居民协作活动，合计 **33 处地图内实际交互设施**，分别绑定三个现存街区。保留原先44个区域街区设计、NPC、房屋、商店与公会。
- 早间 `06:00—13:00` 登记、午后 `12:00—20:00` 协作、晚间 `18:00—24:00` 交接。玩家需前往真实坐标完成，时间未到或前置未完成会给出明确提示。关闭时地图设施会变暗。
- 世界侧利用 `WorldGeography.reachable()` 与地形碰撞判定选取原街区附近的安全交互点；与已有任务、建筑入口、V6调查点互不覆盖，主线角色和旧房屋保持可用。
- 每座城镇新增 **不同的特色商店商品**，全都来自正式 `items.json` 道具目录，继续由现有 `RPGCore.buy()` 计算价格，原商品不删减。
- 各城的 NPC 对话根据所在聚落、时段和活动完成状态增加本地消息，同一大地区下不同城镇不再只能共用区域闲谈。
- 依托原 `rpg` 存档结构记录 `town_ecology_v7[map_id][event_id]`，领取社区报酬一次后不可重复刷取；旧存档不存在该字段时按尚未参与处理。
- 小地图绘制街区生活交互点；功能手册「地区探索」统计 **已完成聚落 x/11** 和当前聚落三个环节的营业状态；地图 HUD 显示当前聚落 `x/3` 进度。
- 序章期间隐藏新增的街区活动，以免覆盖开场剧情。

## 核心关联文件

## 审计与验证状态

静态交叉核对：11 份正式聚落配置、33 条互不重复的现场正文、33 个唯一活动 ID、11 种不同的特售商品、对应已有街区及对应正式物品 ID，**均一致，无缺项**。

GitHub Actions 自动化已配置，但 **本批 GitHub 执行环境在审核时失败：作业未分配 runner，记录没有执行任何测试步骤**。因此不能将本批标为“Godot 已通过”。应在 Actions 可用后重新运行 [独立地图验收工作流](https://github.com/chenyu9512/StarlitChronicle-HD2D/actions/workflows/unique-map-layout-validation.yml) 和核心主游戏测试，并检查实际场景中33处设施是否都生成且可达。

## 未完成及下一批

- 还需要更丰富的 NPC 路线、摊位动画、职业互助任务、节庆表演、美术场景及室内关卡。
- 下一批建议 **V7 第三批：21 张野外地图**的地貌谜题、采集点、天气和昼夜互动，以及恢复 Godot 引擎全链路验收。
