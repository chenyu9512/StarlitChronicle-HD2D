## 最高优先级错误（逐映射明细请看第二张CSV）
1. **B02角色包**：4名角色各自的立绘、战斗图、对话图，共12条历史文件，在迁移后实际指向`foozle_*_down_idle.png`。四名角色只复用了3组精灵，其中两人共用warrior，不能视为4套独立人物的商业化立绘或战斗图。
2. **海岸绘线包**：`palm_tree` → `cherry_blossom_tree`；`crate` → `torii_gate`；`grass`、`rope_coil` → 樱花树；`fishing_net` → 木围栏；海岸地面/水面/建筑/室内 → 同一`foozle_desert_tileset`；3张完整场景背景 → 外景地砖图集。严禁只因能加载就判定“正确素材”。
3. **共享地形包**：19条地形映射最终均解析到同一张`foozle_desert_tileset`。部分地区可以复用绘制规则，但不能把沙漠材质无差别替代水面、洞穴和所有其他地区的地表。
4. **后上传道具包**：岩石、水井等物体名基本相符；`star_lantern`/普通灯 → 纸灯笼，通用酒桶 → 清酒桶，存在文化设定、场景用途与缩放风险。
5. **官方V2**：图像可登记但不代表画风通过；9张海岸怪物静态图仍需核对战斗体型与场景敌人身份，5张Boss候选不可标“正式Boss美术完成”。
6. **收容所**：虽已修复4处错误鱼摊/酒桶指向，但剩余的木箱代床位、药盒、亚麻补给若缺显著医疗设计仍不满足视觉语义精确；需要专用床、药品柜、病患名册、护士工作台视觉设计。
