# 《星灯纪行》V7 第三批：21 张野外地图独立探索生态

> 正典范围：七个地区（海岸、三誓、赤炉、群岛、镜眠、旧洲、天轨）每区 3 张非地下城野外地图，共 21 张。群灯之城的西区修复工地属于城市建设区，**本批不纳入野外21图**。本批为增量功能提交，不是全21图商用美术验收结论。

## 可玩机制

- **21套独立地形课题**：每图的断崖、礁石、工坊热流、废墟、森林、时空异象均有独有课题名，先勘察后采集；遇到本图危险天气扣除存活队员一定HP（最低保留1点），仅触发一次。
- **21处每日刷新采集点**：每游戏日只可采集一次，指定优势天气给予双倍的正式道具奖励；不能用重复点击绕过刷新。
- **21条隐藏通道**：探索前提是勘察+采样；当特定天气或本地昼夜时段满足，即可解开；另外提供隔日再次采样的可达保障，避免天气随机性导致永久卡关。
- **21份唯一秘藏**：实际地图设置独立的可到达位置，通道解锁后可传送至秘藏地点；奖励仅能领取一次；旧存档无记录按未发现处理。
- **移动环境成本**：危险天气按各地图不同程度降低移动速度，同时增加原有随机遇敌概率（仅原本允许遇敌的地图）。
- **84个可触达现场交互对象**：复用现存地形、已有区域贴图和道具贴图，地图标记与功能手册对接。旧式 wild_camp 和 wild_cache 原样保留。

## 数据与存档契约

`data/levels/v7/field_ecology.json` 明确列出21张图的现场坐标、四种事件、正式道具、天气和秘藏。运行层 `scripts/world_field_ecology.gd` 将记录增量写入原有 `rpg["field_ecology_v7"][map_id]`，不升级存档版本，也不改动已有 72 章、120 条任务与 V6 调查旗标。

## 美术差距与分图验收

本阶段现场标记仍调用 **现有像素道具**，地面依旧使用 **现有分区地图贴图**；已有动态雨/灰/雾和昼夜覆盖层不会让21张地图自动达到商业美术等级。下一轮商业美术应针对每图独立制作：
1. 专属远近景轮廓和生态结构，保留自然遮挡、独立空间比例与美术动线；
2. 独立的断崖/浮桥/潮沟/旧轨/折光/时间裂隙等模块和转场动画；
3. 四个交互点的专属动效及命中特效，夜晚/雨/雾/灰共计至少4类环境截图；
4. 面对实际 Godot 场景逐张截取远景、探索、近景、交互4帧，核对背面穿帮、碰撞与可辨识性。

**不能将“84个可交互点通过静态数据验证”写成“21图已达到商业级最终美术”。**
