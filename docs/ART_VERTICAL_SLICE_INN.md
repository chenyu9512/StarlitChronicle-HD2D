# 晨露村旅人客栈｜可玩美术样板 A1–A5 第一批

## 已实际接入
- 12个原创可编辑SVG源资源：客栈专用8×8图块、柜台、床铺、壁炉、书柜、圆桌、窗户、吊灯、地毯、窗帘、木桶、灯光贴图。
- 原 `map_coast_01__inn.json` 增加独立摆设坐标（14个实例）、7处真实家具阻挡、3个光源；客栈出入口、柜台和仓库锚点保持不变。
- `world_interior_v4.gd` 合并家具碰撞，`first_act_world.gd` 自动切换客栈独立TileSet，`world_interior_art.gd` 实际实例化贴图、饰边TileMapLayer、人物Y排序家具、CanvasModulate和PointLight2D。
- 其他11间首幕V4房屋仍用原有地图与加载方式，不覆盖别的NPC、剧情、地图或存档。
- `smoke_inn_art.gd` 验证客栈的地板图集、道具、灯光、碰撞、服务点、进出并回到商店的完整兼容流程。

## 状态与缺口
此交付是**真实可渲染的原创美术垂直切片**，而非完整商业美术终稿。材质需要手工像素精修，壁炉动态火焰、遮光体、环境音、NPC细节演出、Windows/iPhone截图审美与真机验收仍未完成。CI成功只能证明相关运行时行为和资源导入，不等于成品画面与示例参考图同等质量。

## 第二批光影修复
- 客栈3处点光源增加轻微动态明暗变化；实体建筑隔断提供3处遮光多边形，贴合现有碰撞结构。
- `FirstActWorld.sync_world_clock` 将昼夜状态同步到当前室内 CanvasModulate 和 PointLight2D，角色无需离开建筑重新进入。
- 回归测试检查遮光体、灯光和白天/夜间切换，仍需人工审美验收。
