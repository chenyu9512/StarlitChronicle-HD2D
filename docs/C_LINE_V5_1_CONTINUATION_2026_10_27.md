1. **制作原档**：保留真实PNG、动画序列、骨骼源、ZIP、地图源文件；删除无图片语义的macOS AppleDouble附属目录以及与原包完全相同的重复导入元信息。按Git SHA逐个定位，所有正式运行素材和有动作时序语义的重复帧不删除。
2. **候选素材**：从候选与原档清单排除7张伪PNG（macOS `._` 文件）；候选条目由756改为749。清单与真实原档一一对应；不把候选自动套到NPC身份或地图碰撞上。
3. **正式运行**：101项优先运行契约保留在既有res://位置，注册槽均在全局美术目录中；不移动B02/B03/角色、场景、瓦片资源。
4. **DLC主题**：修复单图覆盖记录已失效时无法真正恢复的问题；卸载激活中DLC时若写入索引失败尝试恢复原主题；加入全局主题预检查报告（适配、回退、被个人替换优先覆盖的数量），首页一键应用显示实际有效覆盖数。
5. **一键制作批量DLC**：增加 `tools/build_c_art_dlc_manifest.py`。用户把PNG/JPG/WebP置于与`assets/art/...`一致的相对目录，执行生成命令后，在首页导入manifest并一键启用；可加`--strict`要求覆盖所有注册槽。导入时仍由Godot检验每张素材尺寸、比例和图集契约。
6. **清理边界**：即使SHA相同，角色画像的runtime别名、怪物的图鉴/战斗ID、合法动画帧序位、不同地图所用的建筑片段保留，避免破坏路径引用与动作时序。

## 一次性批量DLC操作
```bash
python tools/build_c_art_dlc_manifest.py /your/art_pack --id my_style --name "我的统一画风"
```
在`/your/art_pack/assets/art/...`按游戏原路径放置替换图，运行命令输出`manifest.json`。在标题页→美术管理→导入DLC→选择manifest→一键应用全局画风。无需复制正式图片到候选区。
