# 全游戏复用审计与全局应用 — 2026-10-26

## 实际实现基础（非宣称全内容完工）

《星灯纪行》本身已有共享运行时支持：12幕72章主线、20职业、63技能、63地区怪物、66剧情Boss、12幕Boss模板、81武器、54防具、40世界布局、主支线、装备、商店、战斗、存档和地图路由。以上“目录存在／入口已接入”不代表每项都已达到商业成品美术、难度平衡或人工测试质量。

以《勇者斗恶龙》VII～X通用的体验原则对齐：VII 的章节式地区叙事和职业累积、VIII 的蓄力与直观指令、IX 的多职业成长与协作队伍、X 的长期任务与世界反馈。**没有复制该系列专有角色、世界观、怪物名称、剧情、音乐、美术，也没有声称已实现 MMO 联机。**

## 本轮真正全局生效的功能

| 领域 | 原有基础 | 本次补齐的跨章节能力 |
|---|---|---|
| 职业 | 20职业、主技能映射、8阶熟练度 | 20种原创属性配置统一接入装备属性查询；转职不损失基础属性或已修习熟练度 |
| 转职与装备 | 武器装备时检查职业限制 | 转职时同步检查限制，不合法的装备自动归还背包，避免跨职业绕过装备规则 |
| 技能 | 63技能、等级解锁、当前职业技能栏 | 原职业8阶后继承1～3阶战技；仍受角色等级限制；不同职业技能ID按目录去重 |
| 回合制战斗 | 队伍行动序、元素弱点、蓄力、状态和Boss意图 | 行动序现在读取当前职业/装备速度增益；魔法属性真正参与治疗技能结算 |
| 敌人收集 | 63怪、66剧情Boss运行时目录 | 遭遇自动解锁图鉴、剧情Boss非致命解决也计作“已解决”；V3存档兼容保存 |
| 商店经济 | 10档物品、81武器、54防具、购买出售 | 商品按第1～72章逐步开放1～10档，防止序章直接购买终章商品；区域服务同样检查档次 |
| 验收 | 既有剧情／战斗／角色／地图验证 | `smoke_global_rpg_reuse.gd` 覆盖72章、20职业、63技能、63地区怪、66剧情Boss、存读档、价格门槛与职业安全性；并入单次大批测试 |

## 范围界限和后续内容工作

- 保留此前首幕第5/6章原有非致命胜利的故事逻辑；其余66场Boss的专项机制仍需关卡设计与手工验收，不能因统一图鉴入口便声称全部已精修。
- 不批量改写已经商业审过的台词/数值，不复制 DQ VII～X 的实际资料表与独有装备。
- 目前美术资产仍有开发标记和多种回退图；视觉、碰撞、玩家连续游戏体验、移动端UI与商业素材权利需要另设验收。
- 地区城镇／野外商品档次由剧情章节控制，后续可以加地区本地货单；此轮保持现有剧情稳定ID和V3存档协议。
- 全部代码在 `main` 提交。开发期不逐次跑大型自动化，批次结束仅通过 `docs/qa-batch-trigger.json` 触发一次完整 Core QA。任何运行失败都在 `main` 修复，然后再验收一次；不创建分支。
