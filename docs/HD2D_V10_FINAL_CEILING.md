# 《星灯纪行》美术生成器 V10：最终上限与停机标准

**分支：`Main2美术优化版`。本文件定义目标，不表示已经完成商业画质验收。**

## 1. 版本上限
V10 定为**统一美术生产系统的最后一个架构大版本**。后续修复与调优使用 V10.x；只有 Godot/模型 API 根本性变化造成架构不兼容，才评估下一大版本。严禁以版本号代替画质证据。

统一入口整合 V9 语义/辨识度、现有 V4.2 正式图集、AI Provider 高清母稿、V10 历史缺口、288 个内容图标、Boss 动作、海岸波浪与 Godot 主题安装器。被合并工具在**全量一致性验收**前不得删除。

## 2. 覆盖上限与正式规格
正式核心清单以 `data/assets/av_registry.json`、`data/content/maps.json`、`data/levels/v4/interiors/*.json` 为准。

| 分类 | 数量 | 输出 |
|---|---:|---|
| 地区地形 | 8 | 256×256 |
| 正式地图 | 42 | 1152×648，仅背景、不能替代碰撞 |
| 室内材质 | 153 | 256×256 |
| 地区道具 | 64 | 96×128 |
| 正式角色 | 12 | 96×192（4 行方向、3 列动作） |
| NPC | 35 | 96×192（4×3） |
| 怪物 | 63 | 512×128（4 帧） |
| Boss | 66 | 512×128（4 帧基础图集） |
| 地区 UI | 8 | 512×128 |
| **核心合计** | **451** | 与现有 Godot 加载器严格一致 |

必须另外维护：16 张地面/水面正式图集、109 个历史美术正式槽位、7 个额外 UI 图标、288 个内容图标、66 套 Boss 专项动作图集、8 套海岸波浪动画。**上述数字不是可直接相加的独立美术数量**，以语义 ID 和真实引用关系检查覆盖。

## 3. 画质的最大生产预算（防无限迭代）
- 高清母稿单边最长不超过 **4096px**，单个 PNG 不超过 **32 MiB**；游戏运行图必须仍使用上述精确规格，不能以 4K 原图直接替换 32px TileSet 或 4×3 行走图。
- 一个语义 ID 最多 **4 个候选造型**，每个候选最多 **3 轮自动精修**。失败则进入人工复审队列，**不能自动挑一张不合格图充数**。
- 付费高清绘图默认关闭，每批最多 **16 个任务**，必须由执行方明确提供成本上限。未配置模型、密钥或预算时只生成任务，不得声称已经产出高清原画。
- 画质要求为角色/怪物/Boss **轮廓、服装、武器、身份一致性**；地形无接缝；建筑门洞/脚点/比例与碰撞匹配；12 帧人物动作在四方向均真实不同。
- 像素相似度、轮廓分数、色彩差距只是**排查重复的辅助指标**，不能拿固定分数冒充“商业画质已通过”。

## 4. V10 成品出厂门槛（全部满足才停止升级）
1. 451/451 核心槽位均有解码正确、规格正确、哈希匹配、语义 ID 匹配的运行文件。
2. 补充系统的 109/7/288/66/8 项覆盖及引用完整，不允许因统一替换而消失。
3. **每份正式发布素材都有该哈希对应的美术/身份审核记录**；程序自动生成候选图不得自动写成 `visual_approved=true`。
4. Godot 4.7.2 完整导入、基础脚本、实机画面截图及真实玩家无作弊路径验收通过；地图入口/室内出口/遮挡/碰撞与原任务进度不退化。
5. 全量替换、再次切换、存档恢复、失败回滚验证通过；P0 阻断数为 0。
6. 生成耗时、游戏帧率和内存按**明确的目标设备**实测登记。尚未指定 iOS/PC 基准硬件时，**不得编造 60FPS 或固定性能已达标**。

## 5. 对旧版一键清理器的禁止条款
此前独立交付的 `main2_merge_regen_replace_cleanup_v10.py` 将“没有在一部分注册表字段出现”视为可删除条件，**覆盖不到脚本动态路径、专项 manifest 和部分运行引用**。它不能作为可靠的旧素材删除依据；**禁止直接执行旧版自动清理步骤**。

合法清理流程必须是：扫描完整 Git 跟踪树、场景/脚本/GDScript 动态路径、官方主题/manifest、当前完整运行引用 → 输出逐文件候选清单 → 截图和引擎验证 → 备份 → 删除经过确认的死文件。不能仅凭时间戳、重复文件名或某一个 registry 清空备份，也不能未经确认清除所有旧素材。

## 6. 结论
**V10 的上限是商业发布级生产管线与全游戏画面验收，不是承诺“任意图片一次生成就完美”。** 代码上限、成本上限、资源规格和验收门槛固定。任何一项没有通过，记录为“未测试/未通过”，而不是继续制造 V11 版本号。
