# 《星灯纪行》剧情演出 V1｜P0—P3 实装与发行验收

**状态**：已直接接入默认分支 `main`，依赖现有 Godot 4.7.2 主场景 `scenes/first_act.tscn`、完整72章正典和原版 V3 存档。本文记录可验证的已执行功能，不把程序化预览镜头冒称成最终商业CG。

## 问题与修复

过去「新的旅程」执行 `_start(false)` 后立刻显示自由行动地图，导致剧情数据库里成熟的九场序章没有任何初次观看铺垫；各章进出只是替换任务追踪，Boss与三结局没有可复用的视觉演出管理。

本轮启动顺序更新为：

1. 玩家在正式标题页选择「新的旅程」。
2. 游戏初始化V3存档（仍以 `chapter=0,scene_index=0` 启动），创建和锁定世界。
3. `CinematicDirector` 播放《被遗忘的星光》冷开场。背景使用现有原创海岸灯塔美术；简短对话和合成音乐提示引出悬念。玩家可逐句按键或触屏继续，也可略过视觉演出。
4. 恢复玩家探索控制，原序章九个实体互动目标按顺序出现。每场目标首次触发专属演出卡，再回到已有 `story/campaign/prologue.json` 的正式对话与奖励效果；跳过片头绝不越过正式任务。
5. 第九场《十年之后》完成后，原 `story.prologue_done` 标记生效，进入第一章，同时播放「第一幕·白砂海岸」章节标题，不再只有一条调试式Toast。
6. 以后72章章名、每六章的幕名与289个 `opening/investigate/crisis/resolve/ending` 场景的镜头/情绪节拍，以现有正典元数据为权威，不另造互相冲突的剧情。

## 剧情转场等级

- **日常建筑与旅行**：环境继续运行，轻量位置说明卡，不阻断地图逻辑和正常存档。
- **普通章节开场**：一张可读性高的标题卡；六章一次大幕使用幕名与区域主题。
- **调查与回忆**：目标节点的短镜头聚焦及低音量提示，不滥用大幅震屏。
- **重大冲突与Boss**：危险色彩/短促提示、镜头冲突构图；胜利使用不同音效与返回原任务状态。
- **序章黑星与失踪**：全屏情绪演出、原剧情对白继续控制事件标记，序章最后由十年跳跃卡衔接第一章。
- **终章三结局**：选择后的标题演出与现有正典尾声剧情合作，不替代A/B/C的资格判定或奖励控制。

## 存档契约与中断恢复

- 每个视觉片段记录 `flags["cinematic.<cue>.seen"]`；**跳过视觉演出标记的是“已看演出”，不是“已完成剧情”**。
- 正在播放的片段写入 `rpg["cinematic_checkpoint"]`，正常观看/跳过后自动移除；新游戏中退出并继续可重放未看完的片头。
- 正式文本已看状态由独立的稳定场景ID控制 `flags["cinematic.dialogue.<scene_id>.seen"]`，已读才能使用跳过对白。
- 继续现有旧存档不强制播放新冷开场，不更改72章任务ID、角色数据、装备和结局旗标。
- 头less自动化模式省略真人观看动画的输入等待，单独的演出专项测试可显式强制测试真实导演状态机，确保CI不会因为等待玩家触控而超时。

## 自动化验收

- 专项：`.github/workflows/cinematic-validation.yml`，执行 Python 正典校验、Godot编辑器解析及实际9序章/跳过/保存/恢复/章节数据测试。
- 总体：`.github/workflows/godot-core-validation.yml` 纳入 `smoke_cinematic_flow.gd`，继续执行原72章战斗/剧情/任务/存档回归。
- 预览：`.github/workflows/desktop-preview.yml` 可导出Windows与Linux临时可运行包；其通过只说明引擎导出成功。

## P3 真正上市之前还需要的人工验收

1. **逐帧审美**：在实际 16:9、19.5:9 宽屏以及iPhone安全区内看标题、肖像、分镜与字体，检查是否遮住主角或台词。
2. **音乐**：当前只有原生短音提示，不能将其称为商用品质的完整配乐；需要独立原创序章主题、城镇生活氛围、黑星事件音乐及演员音效，统一响度。
3. **CG/动画**：全屏使用项目已有背景；黑星流星、灯塔熄灭、十年后的同镜头物件变化等仍需要专属动画和真实场景人物动作，不能由静态故事卡直接替代。
4. **长篇节奏**：72章自动流程测试不等于真人通关，需独立玩家验证前25分钟节奏、全部章过渡、重要剧情跳转疲劳、分支台词与Boss演出强弱。
5. **性能/安全**：真实Windows/Linux/iPhone设备监测帧时间、内存、音频开销、视频过场/触控切换、应用切换和重复读档。
6. **字幕辅助功能**：必须真实验证字体大小、输入响应、自动字幕速度、对比度、听力/视力障碍及多语言排版。

### 结论

**P0–P3 系统代码和自动化回归已落地；美术终稿、正式音乐与真实设备完整体验尚未通过商业发行人工验收。** 不得以“headless测试全绿”替代“玩家认为开头已经达到《勇者斗恶龙》成熟商业演出标准”。
