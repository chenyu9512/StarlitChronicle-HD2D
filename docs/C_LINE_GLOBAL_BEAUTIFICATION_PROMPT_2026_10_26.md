# 《星灯纪行》C线 · 全局美化提示词与实施契约
日期：2026-10-26

## 角色与开发目标
你是具有成熟JRPG经验的原创高清2D美术总监、UI设计总监、Godot 4.7.2技术美术总监。
目标不是复制别人的作品，而是形成具有《星灯纪行》自己身份的高清2D冒险：好看的世界、更可信的NPC生活、清晰的战斗信息、风格统一的操作UI，以及真实可玩的晨露村—海岸—前三章样板。

## 总提示词（可直接复制到美术制作工作流）
请严格依据《星灯纪行》现有角色身份、原创世界观、地图结构和真实资源路径，为白砂海岸、晨露村与前三章设计一组风格统一的原创高清2D游戏素材。画面采用深海蓝 `#081626` 作为阴影底色、星灯金 `#E8C687` 作为交互点睛、暖纸白 `#F6EFDE` 作为文字和明亮物体色、海雾青 `#86C8CB` 作为水体和次级反馈。村庄以潮湿石墙、海港木梁、船帆布艺、清晨雾气、暖黄窗火和生活化家具为特色。人物保持原创Q版比例和现有衣服关键细节；环境具备远、中、近景层次、地面阴影、室内遮挡与昼夜色温。交互门口、道路、碰撞、NPC站位、任务引导和战斗目标必须保持清晰。UI优先保障iPhone横屏的阅读、触摸反馈、操作对比度与正确按钮层级；不能被粒子特效、遮挡或强闪烁盖住。

生成前务必读取该目标资源在 `data/assets/c_art_catalog.json` 中的路径、身份、尺寸、atlas标识和 `curation_tier`。各素材逐项生成，不要一次性把静态肖像伪装成动画。逐帧角色以现有四方向三帧 `3列×4行` 为技术契约，行顺序为下、左、上、右。SVG瓦片源稿不能被不匹配的PNG直接覆盖；可先导出与原尺寸匹配的PNG并在首页本机替换预览。外部素材必须通过使用及公开再分发授权审核。只参考成熟JRPG设计通则，不复制其他游戏、动漫作品的角色、服装、场景、地图、UI、台词或商标。

## 当前仓库接入路径
- `scripts/c_visual_design.gd`：颜色与按钮状态/面板框样式。
- `data/assets/c_visual_prompt_profiles.json`：21+种类别提示词及17项重点资源的专属描述。
- `scripts/c_visual_prompts.gd`：把当前素材元数据组合成可复制的制作任务。
- `scripts/c_art_manager_ui.gd`：标题画面 → 美术工坊 → 选中资源 → 生成美化提示词 → 查看/复制。**只生成文字，不会自动替换图片，不会提交GitHub。**
- `scripts/first_act_ui.gd` / `scripts/map_hud.gd` / `scripts/d_title_screen.gd` / `scripts/battle_hud.gd` / `scripts/world_ambience.gd`：统一视觉效果的最小化接入。

## 验收与安全
1. `python tools/validate_c_visual_prompts.py` 确认提示词目标与真实资源存在、分类完整、接入标记齐全。
2. `godot --headless --path . --script res://tools/smoke_c_visual_prompts.gd` 通过引擎校验控件、按钮样式与提示词面板。
3. 运行正式 `scenes/main.tscn`；标题、首页美术工坊、地图、对话框、营地、战斗、日夜变化逐个截图。
4. 检查iPhone横屏安全区、16:9 PC、低性能开关及原图恢复操作。
5. 剧情、战斗数值、道具奖励和存档回归仍归D线集成验收。本批不修改业务数据和交接事务。
