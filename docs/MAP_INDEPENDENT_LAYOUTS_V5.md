# 《星灯纪行》40张地图独立尺寸与空间布局 V5

> 开发分支：`main`。本文件依据40个现存独立 `data/levels/v3/map_*.json`，而非概念文字统计。请将「可玩几何结构」与「商业级手绘场景」分开验收。

## 本批真正做了什么

- 40张地图分别配置**不同物理格数**，宽82–102格，高52–72格；不再统一为72×48格。
- 每张地图配有独立的主路线、次级分支、旧街环路、外围探险段、隐藏路径、地形障碍、水道（符合地貌时）、空地和地标，及3个与旧地图核心相连的外围节点。
- 单张地图以 `data/levels/v3/<map_id>.json` 为编辑入口，同时同步 `data/levels/world_levels_v3.json` 回退镜像。不要修改一个版本而忘记同步另一个。
- `WorldGeography.layout()` 按地图独立面积生成物理地形，地图相机、迷你地图及迷雾探索范围随场景实际大小变化；主线和120支线既有坐标保留在旧72×48核心内。
- 迷雾读档将旧72列位图重新映射到新地图宽度，不改变已探索位置或原存档数据契约。
- 对原有城市广场、商店门口、地下城机关、离开地图出口作连通性保守修复，避免扩图把玩家困在房间或道路另一侧。

## 稳定性与验证

- 验证器 `tools/materialize_world_v3.py --verify`：40个独立地图与汇总数据**结构与内容完全一致**，不能在编辑时意外回退。
- `tools/smoke_world_v3.gd`：确认40套尺寸、独立道路签名、各地旧主线目标与区间出口连通，以及障碍、水域和绘制覆盖层顺序。
- `tools/smoke_world_production.gd`：确认40张物理场景、11个聚落、8座地下城、1556个通行锚点、城镇室内进出及地图导航。
- 新增专属 GitHub Actions：`.github/workflows/unique-map-layout-validation.yml`。首个完整通过：[40地图验收 #40186334320](https://github.com/chenyu9512/StarlitChronicle-HD2D/actions/runs/40186334320)。
- 地图完整回归通过：[Map UI Gameplay #40186334169](https://github.com/chenyu9512/StarlitChronicle-HD2D/actions/runs/40186334169)。

## 严格未完成事项

- 目前地图由**独立数据驱动的 TileMapLayer** 生成，不代表已经制作40张手绘 `.tscn` 地形或40张独立背景插画。
- 各地区仍共享区域 TileSet；主要城镇建筑艺术、8座地下城专属机关美术、剧情角色表演与事件谜题、环境音乐、战斗镜头仍需单独生产。
- 下一轮需地图设计师按地图逐张**实玩**审查视觉构图、道路长短、相邻区域转换、角色与物件遮挡、可探索支路价值、素材重复率、跳转成本、遇敌密度和宝箱奖励节奏。数值验收与美术验收不可混写“已完成”。

## 后续编辑规则

1. 先修改唯一地图源 `v3/<map_id>.json` 与镜像集合，保持总共40张。
2. 优先保持原72×48范围内的剧情、NPC和室内门坐标；调整必须连同120支线世界锚点和保存兼容迁移一起修复。
3. 只为具体地图增加道路、岩壁、水域、平台或专属谜题，不得再次批量覆盖为同一几何模板。
4. 提交前确保地图专项CI绿色；不要用“Godot载入成功”替代真人完成地图探索验收。
