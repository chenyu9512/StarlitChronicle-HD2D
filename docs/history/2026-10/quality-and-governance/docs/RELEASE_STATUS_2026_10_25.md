# 星灯纪行｜2026-10-25 工程交付与商业版验收状态

> 本文给开发者与体验者说明实际完成的可执行功能、对应测试，以及与正式上市产品之间的差距。自动化验证绿灯不能取代发行验收。

## 已可执行的交付

- 主工程：Godot 4.7.2，主场景 `scenes/first_act.tscn`，默认分支 `main`，复用完整十二幕、72章主线控制器、原存档/装备/战斗/任务系统。
- 地图 V2：40个可玩地理区块 + 2个封存原型，8个地貌地区，72×48格区域地形、11个聚落、6种街道结构、8座不同地下城，以及可进入并正常退出的建筑室内。
- 地图UI：迷你地图、当前区域地图、放大地区地图和世界航路，玩家/任务/出口/设施/NPC/宝箱标记；安全最短路径只允许执行下一段已解锁道路。
- 城镇生活：原有40名 NPC 可在各地区交谈；NPC 日夜位置、首次谈话记录、地图/时间/天气提示，商店按物品定价买卖，客栈与祈灯祠恢复HP/MP，工房按配方锻造，公会完成3次有效战斗后领取每区唯一委托奖励。
- 野外与存档：城镇内没有随机野怪；野外营地每天一次免费恢复并降低随后一段路的遇敌压力；建筑室内位置与返回室外的坐标保存至原 `rpg.world`，读取旧存档无需版本重置。
- 昼夜和地区天气：晴、薄雾、阵雨与火山灰的程序化叠层，不依赖联网和额外硬件。

## 严格区分“成品级架构”与“商业发行成品”

目前不能宣称已达到《勇者斗恶龙》系列的商业发行制作水准。仍缺少：

1. 完整40区逐张人工修整地形，城市内部每间房的专属摆件、NPC动态行为与演出，8座地下城的独立Boss场景及完整解谜。
2. 美术总监级风格统一、正式人物动画/怪物演出、光效、各区域 BGM、原创 SFX、配音与音频混音及合法授权记录。
3. 六章起至72章的完整手动实玩验收、剧情分支回退验证、难度与经济数值长期平衡。
4. iPhone 实机帧率、触摸反馈、安全区、过热、电池耗电与代码签名；App Store 审核/订阅与发行资料。本轮只交付桌面预览，**不代表已有可上架的 iPhone 签名安装包**。
5. Windows/ Linux 预览包的真实桌面玩家测试、自动崩溃收集（经用户同意）、无障碍设置、兼容性矩阵和数字签名。
