# 星灯纪行｜序章 P4：世界现场演出与真实画面审查

本阶段承接 P0–P3 冷开场、9场序章、289个分镜与72章主线，不另建剧情状态或新分支；执行位置为原仓库 `main`。

## 导演目标

**从静态故事卡过渡到“灾难确实改变了玩家刚刚熟悉的世界”**：祭典中本应闪耀的灯架，在黑星坠落后变暗；受影响的村庄保留异样的环境色调；记忆消失与十年过去不再只靠一行说明文字。

这借鉴成熟JRPG的“温暖日常 → 不可逆的事件 → 可见的世界后果 → 主角动机”，不复制《勇者斗恶龙》的具体地图、美术、音乐或人物。

## 运行时组成

| 模块 | 真实运行效果 |
|---|---|
| `scripts/cinematic_scene_fx.gd` | 剧情背景上的动态黑星、灯光依次熄灭、灯塔光束、祭典灯光、记忆粒子和十年光照流动 |
| `scripts/prologue_world_stage.gd` | 游戏世界中的黑星轨迹、灾后昏暗与失光星灯、遗忘氛围和十年后的环境色调 |
| `scripts/first_act_world.gd` | 从现有地图的场景物件定位星灯，控制视觉阶段但不改变地形碰撞、NPC/商店和剧情点 |
| `scripts/first_act.gd` | 世界演出仅由原 `chapter / scene_index` 派生，已读/已跳过/重新读档共用正典进度；剧情时海岸环境音平滑降低，结束恢复 |
| `scripts/cinematic_director.gd` | 真实全屏合成动态场景FX、键盘继续与略过、结束后柔和淡出；在新演出启动时安全取消旧渐变 |
| `data/cinematics/prologue.json` | 原九场序章中的七个关键事件特效指令，不覆盖故事对白 |

## 九场序章的实际世界状态

| 序章阶段 | 地图效果 | 玩家感受 |
|---|---|---|
| 0–1 灯祭清晨、岚音药草 | 正常日光 | 先建立熟悉与安全感 |
| 2–4 星灯祭、传说、登塔 | 温暖浮灯与节庆光点 | 被守护的故乡确实有温度 |
| 5 黑星降临 | 移动的黑星、紫红轨迹和冷光 | 温暖的日常被外来事物打断 |
| 6 灯灭后 | 世界光线冷却；星灯物件降亮 | 灾难在玩家回到地图后仍留下后果 |
| 7 无人记得澄舟 | 冷色调、淡淡的记忆微粒 | 视觉节奏由恐惧转为失落 |
| 8 十年之后 | 不同于灾后夜色的褪色晨光与灰尘 | 时间跳跃不只是字幕 |
| 转入第1章 | 不再保留临时灾变叠层 | 进入新阶段不会出现永久黑屏 |

## 尚不属于最终商业美术的内容

- 此批是高性价比 2D 程序视觉特效，尚未做正式分镜逐帧人物动作、独特CG绘制、灾难期间的完整逃离交互关卡；
- 目前音频有程序化叙事提示、海岸环境声及电影演出时的自动混音，还需要原创完整 BGM、混音和更丰富的角色环境互动音效；
- 没有完成真实 iPhone 与桌面玩家对前25分钟的情绪曲线、字幕阅读、照片敏感用户可视舒适度和帧率的手动验收；
- GPU截图“存在且彼此不同”不等于构图达到《勇者斗恶龙》成熟商业成品画质，需要逐张审美复核。

下一项优先深化**序章玩家可操作的逃离事件与关键角色动作调度**，其后才是新增资源成本较高的原画/音乐全生产。
