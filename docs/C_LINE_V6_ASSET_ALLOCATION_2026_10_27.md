# 《星灯纪行》C线 V6 · 未用美术批量分配与游戏内图标接入

## 本批实际范围
- 以既有`main`为基线，所有操作直接提交`main`，不创建分支或PR。
- 749条制作原档PNG在候选清单登记具体`region_id`、`map_id`、`intended_role`及可选正式实体ID。
- 667张已有CC0外部运行候选、472项核心备用也全部对应具体区域/地图/用途，形成1888条分配行（与前次统计相同集合）。
- 90种道具、81种武器、54种防具、63项技能（共288个内容ID）明确分配给已有Owlish 32px图标；`scripts/c_art_item_icons.gd`根据`data/assets/c_art_content_icons_v6.json`加载，通过`CArtOverrides.texture`接入游戏菜单。
- `scripts/rpg_menu.gd`的背包、装备、技能、图鉴、商店、锻造、出售显示图标，原按钮业务和存档结构保持不变；不修改战斗/剧情/地理碰撞。
- 演示、参考和不能直接匹配比例/动画的素材仍保持候选，不会装成已经在地图或Boss里真实显示。`source_packs`仍由`.gdignore`阻止导入。
- 两套原有DLC 28个映射与全局替换优先级保持不变。

## 分配定义
`allocated` = 记录目标游戏区域、地图、可选实体及使用场景；`runtime_menu_icon` = 游戏菜单代码真正读取的图标ID；`adaptation_needed` = 需逐帧切片/场景尺寸/风格匹配，未接入运行。
核心备用中部分资源可能已被动态引用，不能据静态统计称为未使用。图标内容ID可共用同一张图，因此288条映射不代表288张不同图片。
