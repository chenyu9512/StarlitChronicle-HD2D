## 本次真实代码变更

- `scripts/c_art_overrides.gd`：地形DLC的`group`展开后，同一相对图片路径首次解码、验证并写入`user://c_art_packs`一次；后续对应目标继续验证原始图集尺寸，只复用已验证的文件路径，不再重复解码同一PNG。
- 对应现有`terrain_ground`的11槽与`terrain_water`的10槽；既有单一`target`导入继续保持独立目标文件，避免错把普通槽位合并。
- 遇到尺寸不兼容、路径不安全或图片不存在仍中止本次导入，并回滚这次新增的PNG；不替换`res://`原画。
- `tools/smoke_c_terrain_group_import_v9.gd`：在`user://`临时生成两张256×256图片，通过公开导入API安装并预检查映射21槽、仅两份PNG、纹理身份复用、个人单图覆盖优先级，最后恢复原主题、卸载临时DLC并清理输入文件。
