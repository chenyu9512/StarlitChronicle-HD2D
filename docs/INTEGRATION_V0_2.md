# 星灯纪行 v0.2.0 剧情骨架、数据整合和隐藏调试工具

## 实际实现
- 原型村庄 / 遗迹仍然可玩、原有战斗与存档保持兼容。
- 主仓库吸收 `content/full-story-v1` 的 72 章和九场序章、职业、人物、选择、结局策划数据，以及独立的 story preview。
- 主仓库吸收 `feature/content-foundation-v0-2` 的 11 类离线数据图鉴（NPC、武器、防具、技能、任务、怪物、地图等）和 JSON 校验脚本。
- 新增主线剧情运行器：从菜单进入、逐句对白、条件旗标、选择、NPC 情节、剧情 Boss 战斗接入、奖励和存档；未进入正式地图/战斗的场景通过叙事UI执行。
- 金手指秘密入口：点击右上方金色小星星 5 次（4 秒内），或桌面键盘 F10，输入 `9169`。
- 金手指包括全队恢复、金币/药草、强化等级和属性、无敌、禁遇敌、经验五倍、传送、章节调试快进。
- 状态字段存档向后兼容 v1 JSON；解锁状态和战斗作弊开关不会持久化；金币等产生的物品/等级变化会持久化。

## 未实现 / 后续制作
- 72 个章节的独立 HD-2D 场景地图、美术资产、角色多方向动画、实际地图碰撞、NPC 分支事件、每个首领的专属动画与技能、平衡调参尚未完成。
- 大纲内的场景需要逐一落地到世界地图，当前剧情运行器是交互剧情/战斗桥接，而不是整套72章全场景的完整 JRPG。
- 最终分支结局文本已经存在，但尚未完成独立的结局CG/过场演出系统。
- `9169` 是本地隐藏菜单密码，不是加密安全边界；发布商业版建议在编译发行包中移除此入口或以开发者专用构建宏隔离。

## 测试
1. 在 Godot 4.7.2 打开 `project.godot`，F5，原有村庄和遗迹操作应正常。
2. 打开菜单，选择 `主线剧情 · 十二幕七十二章`，完成序章，验证章节进度和关闭重开。
3. 触发主线 Boss，确认可战斗、胜利后可继续；失败不会越过剧情条件。
4. 在右上角星星连点 5 次，输入 9169，使用功能，保存并重启验证永久资源和临时开关的差异。
5. 运行 `python tools/validate_story.py` 与 `python tools/validate_content.py` 以及 `python tools/validate_project.py`。

## iOS
使用既有 Godot iOS 导出和 Codemagic 云端构建配置。隐藏入口通过普通 Godot Touch GUI 实现，不依赖电脑键盘。
