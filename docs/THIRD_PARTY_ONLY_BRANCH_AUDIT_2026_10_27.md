## 审计用法

在项目根目录执行：

    python3 tools/audit_third_party_only_branch.py --out third-party-migration-audit.json
    python3 tools/audit_third_party_only_branch.py --strict

脚本只读、零外部依赖：逐文件检查新旧 Git blob 是否一致、来源路径白名单、旧 SVG 是否仍存在、命名分辨率是否失配；同时列出不同角色共用来源的身份冲突，以及运行时的已删 SVG 直接引用与动态资源路径。

严格检查出现结构错误或待解决风险时退出非零。**静态检查成功不等于 Godot 导入、场景效果、动画表现或商用画面成功。**
