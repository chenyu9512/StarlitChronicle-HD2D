## 需要禁止作为最终版本的错误映射

- `tide_lighthouse_landmark.svg` → `paper_lantern_32_x_32.png`：32px灯笼不能替代大型灯塔地标。
- `harbor_crane.svg` → `bamboo_cluster_32_x_32.png`：竹丛不能表现港口吊车。
- `sign.png` → `lotus_lily_pad_32_x_32.png`：路牌变荷叶，严重破坏路径引导。
- `cottage.png` → `fallen_log_32_x_32.png`：屋舍变倒木，无法成立。
- `map_coast_01_house.svg` → `shrine_wall_segment_32_x_32.png`：单块墙面不能充当住宅立面。
- `walk_4dir_3frames.png` → 单张角色攻击/行走图：原有3×4图集逻辑不能直接切片。
- 海岸地形与水面曾共同指向沙漠地形大图集：必须依据原图的32px网格和语义重切片，不能仅重定向路径。
- 多名原创人物、章节Boss复用同一套第三方角色/Boss形象：必须为剧情身份建立一一对应，不能仅按模板职业分配。

## 下一道不可跳过的商业交付门槛

1. 先对照第三方可用原始素材找到**完整**角色方向帧、海岸地形、港口建筑/室内、Boss真实身份的适配来源。没有对应图的槽位必须登记缺口，禁止用无关图片代替。
2. 制作独立的收容所、酒馆和浅滩关卡场景，灯塔制作成正确的大型地标；B/D线共同确认地理锚点、门口可达和返回逻辑。
3. 编写Atlas切片与导入转换，将原始PNG打包成稳定、可导出的运行时纹理。静态文件有源不代表图集像素布局兼容。
4. 在 Main2 的干净检出上运行：
   ```bash
   python tools/audit_act01_third_party_art.py
   python tools/audit_act01_third_party_art.py --require-commercial
   godot --headless --path . --editor --quit
   python tools/d_control/run_full_smoke_suite.py
   ```
   Python 审计与 Godot 引擎冒烟测试分开执行；上方命令需要在已安装相应运行时的完整本地克隆中执行。
5. 依六章检查截图、角色方向动作、房屋门口、地图清晰度、光照、战斗及回归存档。所有P0为零、角色和场景完成视觉签收才可说是商业级第一幕。
