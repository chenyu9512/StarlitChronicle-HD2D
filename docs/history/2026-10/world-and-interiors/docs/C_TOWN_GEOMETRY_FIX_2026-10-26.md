# 《星灯纪行》村镇建筑 / 道路 / 树木冲突修复（C线联合B/D接口交付）

日期：2026-10-26。全部代码直接提交 `main`，无新分支或 PR。参考经典日式回合制RPG（如《勇者斗恶龙》）的物理通行和门口可读性原则，所有资源均为本项目已有资产，没有引用原作版权素材。

## 现场定位（真实运行路径）

- `scripts/world_geography.gd::layout`：房屋先占用格子并设为阻挡；之后调用 `_road` 铺设故事道路、出口、扩展节点，并可能直接用 `walls.erase` 抹去建筑碰撞。最终校验原本只处理任务坐标，没有再次封闭房屋。
- `scripts/first_act_world.gd::_decorate`：正典建筑之外，还有 `act01_layouts.json` 的 `cottage` 纯装饰假房子；它们既没有建筑ID，也没有室内，容易造成“看到房子却无法进入”的误解。
- `world_structure.gd` 原来的门口距离依据固定 `cells.y*TILE*0.5-35` 而非正典入口 `building.door`。交互标记又设在被房屋占用的 `door` 格，导致艺术表现、碰撞和选择目标不一致。
- `scripts/world_coastal_scene.gd` 的树木放置此前没有避让房屋/门口/主路，例如 `map_coast_01` 的 `dew_flower_scrub` 原始配置位于公会屋顶范围内。纯视觉 y-sort 不能修正物理位置。

## 运行与存档规则

- 建筑主体的整个正典占地（当前偶数size在旧地图上的覆盖规则是 `center±size/2` 的包含式区间）必须阻挡角色；人物的碰撞脚点不会穿墙。
- `door` 是建筑实体边界，不是可穿透碰撞孔。玩家站在 `door + (0,1)` 的前台阶按互动键进入室内；退出回到真实前台阶，不能在墙里读档。
- 剧情道具/NPC不应挤在屋顶、树根或隔绝地块。预置坐标如果与房屋冲突，视觉交互标记转移到附近可达的地砖，不改任务旗标、奖励或逻辑ID。
- 高树根据树干根部做一格阻挡；如该格阻挡会隔绝房屋、主要路口、必达任务或出口，则拒绝新增该格碰撞，以保持任务通行。低矮草丛作为无碰撞装饰。树冠沿原有同层Y排序遮挡，不使用3D模型。
