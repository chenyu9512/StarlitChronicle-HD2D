# 星灯纪行｜V7 第一批：八座地下城独立机关

> 正式游戏主线、剧情旗标、120条支线、40张地图V5与地图探索V6继续沿用。本批在 `main` 新增 **八套不同的机关逻辑、32个物理地图装置、八份独立密藏奖励**，而不是仅更换机关文案。

## 独立规则

| 地下城 | 机制 | 交互方式 |
|---|---|---|
| 潮声洞窟 | 潮汐石阀（`sequence`） | 三个不同石阀依照潮痕顺序依次推动，错误顺序复位 |
| 誓石神殿 | 守誓天平（`balance`） | 配重增加两格、卸重一格；平衡到目标值后固定指针 |
| 灰烬铁路 | 铁轨电路（`circuit`） | 三个开关各控制不同的相连导轨灯组，使指定亮暗组合成立 |
| 深潮神庙 | 水位控制（`water_level`） | 分别进水、放水及读取观测灯，要求实际操作过双阀并回到目标水位 |
| 银玻璃塔 | 双镜折光（`mirror`） | 分别旋转左右镜面并切换镜像，满足双角度和镜像状态 |
| 星墓秘殿 | 时间相位（`time_phase`） | 顺时、逆时、跳刻改变模四时相，需操作过三座转轮并校准 |
| 岁影尽头 | 七灯音钟（`rhythm`） | 按独有四音节律演奏；节律错误时重来 |
| 星灯中枢 | 灯网配电盘（`dial`） | 三个分配盘各独立循环三档，使所有支路达到预定组合 |

以上八个状态机采用相互不同的逻辑，不共享一种简单的两开关判定。每座地下城的三座操作装置及宝柜均有独立地图位置，读取 `data/levels/v7/dungeon_puzzles.json`，靠近后可以用游戏现有交互键操作；地图 UI 有对应的专属标记。

## 保存与任务兼容

- 机关状态独立保存在 `state.rpg["dungeon_puzzles_v7"][map_id]`；不改变 `first_act_v3.json` 的存档版本，老存档没有记录时按未解开处理。
- 每座宝柜仅可领取一次；旧版 `dungeon_switch_a`、`dungeon_switch_b` 和 `dungeon_chest` 仍在，不影响原章节剧情与旧存档的 `map.<id>.*` 标志。
- 地图已有V6调查与新V7专属机关并存，奖励相互独立，不能据此认为全部地下城商业级视觉或Boss演出已经完成。
- 功能手册「地区探索」显示八座地下城的已解开数量、当前地图谜题线索和状态。

## 代码与回归

| 文件 | 作用 |
|---|---|

| `scripts/world_dungeon_puzzles.gd` | 八种机关状态转换、先决条件、一次性奖励及旧存档增量恢复 |
| `scripts/first_act_world.gd` | 根据地图实体化机关与典藏宝柜 |
| `scripts/first_act.gd` | 游戏交互、金币和道具结算、事件账本及自动存档 |

| `tools/smoke_dungeon_puzzles_v7.gd` | 八谜题的错误操作、正确通关、地图可达、奖励、防重复与读档检查 |
