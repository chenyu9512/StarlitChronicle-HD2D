# 星灯纪行 A7—A12 美术开发与验收范围

本批对准第一幕两座城镇、盐风古道、潮声洞窟四张可玩区域，不覆盖其他地区的地图、72章剧情、事件触发器或存档结构。

## 已写入运行时的工程
- A7：两座城镇×旅馆、商店、公会、铁匠、民居、祈灯祠共12份建筑立面 SVG，保留旧 `WorldStructure` 程序绘画作为其他世界地区的可运行回退。
- A8：盐风古道水潭、沙草、礁石、木桥与白砂港码头吊机、渔网等实际场景 sprite，通过地图ID专属数据表装入 `WorldCoastalScene`；水纹按现存 water_mask 采样而不是伪造河道。
- A9：潮声洞窟专用钟乳岩、晶石、遗迹祭坛及非阻挡场景光效。原机关、宝箱、Boss脚本与任务触发未改。
- A10：原有四方向行走动画继续运行，新增轻量角色停步呼吸、交互动作反馈与 NPC 美术肖像的休闲漂浮，不声称替代正式逐帧动作表。
- A11：创建不依赖版权曲库的 PCM 环境音源（海浪、港口轻钟、古道、洞穴低频气氛）并在相应实际可玩区域播放；不是正式配乐或配音终稿。
- A12：以真实 Godot GL Compatibility 渲染窗口创建 1152×648 的五张场景PNG及可机读清单，附在 `First Act Visual Evidence` 工作流作为审稿依据。不能将自动截图等同 Windows/iPhone 真实设备签字确认。

## 验收界限
1. A7–A11 新资源在 Godot 实际地图中创建，测试应检查每张地图/建筑的独立实例、贴图、光源、声音和交互。
2. A12 确认5张真实画面及JSON由自动化产出，样张用于人工视觉审查，仍需实际 Windows 显卡/iPhone 设备审查。
3. 美术精修、技能及Boss专用特效、全角色完整逐帧动画、音乐正式混音、适配性能和 App Store 发布不能因为基础测试通过就标记完成。

## iPhone / Windows 人工检查点
- 建筑门口、柜台、NPC的高度层次是否真实；雨雾是否错误遮住室内；地图左右边界无黑边。
- 海水波纹与道路、桥梁实际碰撞对应，静止和移动均没有重复贴图强烈闪烁。
- 洞窟机关、调查点、宝箱、Boss处不被装饰层遮蔽操作热点。
- iPhone 横屏安全区、发热与帧率（目标60 FPS）；Windows不同缩放DPI与手柄操作。

## A13 Deep Surface Pass
- 参考真实游戏截图，将洞窟水纹改为独立青蓝色图集，增加三套纹理透明细节图集，以单层 TileMapLayer 生成草茎、砂贝、岩石裂隙、路面石缝及真实水陆边缘浪花。
- 12处建筑原始立面增加瓦纹、门楣、墙根与挂灯；门灯由 Godot PointLight2D 实际驱动并在昼夜时钟变化时调整亮度。
- Player 四向行走帧保持原样，只加入脚下接触阴影；天气遮罩遵循 V3 实际地图尺寸，不再固定在旧的72×48区域。
- 自动化烟雾测试检查地表细节密度、实际灯光/时钟、洞窟海水图集及地图遮罩边界。审美与 iPhone 设备性能仍须实际审核。
