# 星灯纪行 HD-2D 美术规范（Batch 0）
本次交付的 SVG 是第一轮**可编辑像素风矢量稿**，以稳定角色造型、纹理比例和游戏导入为目标，并非已完成手工精修的商业插画。每张SVG通过 `tools/export_hd2d_svg.py` 在原有画布尺寸导出透明/背景 PNG。
## 统一规格
|资源|画布尺寸|其他要求|
|---|---|---|
|人物 portrait / battle|320×400|RGBA透明；同一人五官、色组、服装标记一致|
|dialogue|192×240|同源缩放；无裁切|
|表情差分|128×160|neutral / smile / worried / determined|
|行走表|96×192|4行×3列；帧 32×48；顺序 DOWN、LEFT、UP、RIGHT|
|地形 atlas|256×256|64 tile；每格32×32|
|地图道具|64×64|独立透明；少数大型96×96|
|展示背景|768×432|16:9，不等于可玩地图|
|怪物立绘|256×256|RGBA透明，尽量不同剪影|
|怪物图鉴图|256×256|有简洁海岸展示背景|
|怪物待机图|512×128|横向 4 帧×128|
## 色彩与风格
海蓝/深绿/盐白/白砂金/少量珊瑚红，左上暖光、右下深色；场景温暖、人物干净、怪物外轮廓容易识别。保留旧 `assets/characters/hero.png`、旧地图和旧怪物不覆盖，防止 v1 存档和旧战斗失效。
## 文件协定
- PNG 导出与 SVG 原稿同目录同文件主名；UTF-8 ASCII小写路径。
- `assets/art/art_manifest.json` 为输出清单的单一事实来源，附批次、逻辑角色/怪物ID、画布规格。
- 批次0=色板与规格；批次1=四名角色、每人肖像/战斗/对话/行走表/4表情。
- 批次2=白砂海岸 atlas、道具和环境画面；批次3=9只海岸魔物的立绘、图鉴和待机表。
- SVG master 与 PNG 两者以 `tools/validate_hd2d_art.py` 校验；只有制作动画、画面接入并完成试玩测试以后才能标记 runtime_integrated。
