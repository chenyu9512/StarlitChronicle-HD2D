# B03 第一幕Boss独立战斗造型母稿

依据主线第2—6章五场Boss设定制作，每场一张独立透明1024×1024 SVG造型。不是之前的512徽章，也没有重做或覆盖B01/B02。

## 设计定位
- ch002 雾潮寄生体：半透明海蜇寄生体 + 碎船铃 + 潮雾触须
- ch003 潮痕守卫：多足礁岩甲壳 + 灯塔透镜 + 锚钳
- ch004 灰帷水手：破船帆、旧航装、亡失航路与幽灯
- ch005 缚潮古兽：角冠深海巨兽 + 拘束金属链 + 潮晶甲片
- ch006 潮歌守门人：非人形海螺圣殿守护者 + 记忆透镜

## 使用限制
这是有独立造型、结构、层次及可编辑路径的第一轮矢量视觉母稿，仍需要美术审查、纹理细化、动画拆件；不要把它们标记为商业定稿或可用的完整Boss动画。请勿用自动工具生成的一致性不足的动作覆盖这些母稿。

神经末端发光、波纹、潮湿材质是统一世界视觉元素，但五个Boss的体形、构造和武装存在明显差异。尺寸1024×1024，透明背景，供Godot SVG纹理导入/后期导出PNG。
